# Changelog

## 1.0.0
First release.
- Per-session `DynamicsProcessing` compressor + limiter applied to other apps' audio through Shizuku (no root)
- Presets (Soft / Normal / Strong / Night) and a fully editable custom preset, 6-band multiband mode
- Per-app profiles (default / bypass / preset)
- Foreground service, Quick Settings tile, start on boot, battery-optimization exemption request
- Live output level meter
- English and French UI
